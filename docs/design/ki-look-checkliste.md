# KI-Look-Prüfliste

Stand 03.11.2026, aus der Recherche (Quellen unten). Jeder neue Screen wird damit geprüft,
bevor Luka ihn sieht. Ein Treffer ist nicht automatisch verboten, braucht aber einen Grund,
der aus dem Moodboard kommt.

## Flächen und Formen
- [ ] Farbiger Streifen an einer Kartenseite ohne Status-Bedeutung
- [ ] Karte in Karte (Kasten in Kasten)
- [ ] Dünner Rand **und** weicher Schatten gleichzeitig
- [ ] Gleiche Kacheln im Raster: Symbol über Titel über Untertitel
- [ ] Überall derselbe Eckenradius, egal wie groß das Element ist
- [ ] Glas, Unschärfe oder Leuchten ohne echten Grund (Ebenen trennen)

## Farbe
- [ ] Verlauf auf Knöpfen oder Flächen ohne Bedeutung
- [ ] Lichtschein, Halo oder Spotlight hinter Inhalten
- [ ] Farbiger Schatten unter Knöpfen („Glow“)
- [ ] Standard-Paletten: Lila-Verlauf, Türkis auf Dunkel, Dunkel mit Gold, Beige ohne Grund
- [ ] Verlaufs-Text

## Schrift
- [ ] Nur eine Schrift (System, Inter) und keine bewusste Wahl
- [ ] Kleine Großbuchstaben mit weitem Abstand über einer Überschrift („NÄCHSTER ANLASS“)
- [ ] Flache Hierarchie: Überschrift und Text kaum unterscheidbar
- [ ] Riesige Zahl als Blickfang ohne Erklärung

## Symbole und Bilder
- [ ] Emojis als Symbole (✨, 🎁, ♥)
- [ ] Symbol in einem farbigen Kästchen über der Überschrift
- [ ] Platzhalter-Illustrationen, die nichts Bestimmtes zeigen
- [ ] Fotos unter starker Abdunklung

## Bewegung
- [ ] Federnde oder elastische Animationen bei Routine-Aktionen
- [ ] Animationen länger als 300 ms bei häufigen Aktionen
- [ ] Pulsierende Punkte oder Dauer-Animationen ohne Anlass

## Text
- [ ] Allgemeine Werbesprüche statt konkreter Aussage
- [ ] Gedankenstriche statt Punkt
- [ ] Derselbe Text zweimal im selben Kasten
